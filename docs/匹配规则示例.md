# 托盘图标匹配规则示例

在应用的“当前图标”页面确认程序名、悬停文字和可访问名称，再在文件夹的“手动匹配规则”中每行填写一条规则。名称可能随程序版本和系统语言变化，下面仅提供填写示例。

| 图标/程序 | 匹配规则示例 |
| --- | --- |
| 微信 | `*微信*` 或 `*Weixin*` |
| ChatGPT | `*ChatGPT*` |
| Everything | `*Everything*` |
| Snipaste | `*Snipaste*` |
| 蓝牙设备 | `*蓝牙设备*` |

`*` 匹配任意长度的文字，`?` 匹配单个字符；匹配忽略大小写。多个文件夹的规则同时匹配时，按文件夹顺序归类。

例如，将微信和 ChatGPT 归入同一个文件夹，可填写：

```text
*微信*
*Weixin*
*ChatGPT*
```

系统图标应尽量使用具体提示文字。例如，蓝牙设备使用 `*蓝牙设备*`，可以避免按“Windows 资源管理器”匹配时把其他系统图标一起归入。

通过选择图标或拖动保存的归属优先于文字规则。若修改规则后归属没有变化，请先检查是否已手动指定该图标的文件夹。
