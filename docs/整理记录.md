# 代码整理记录

## 0.4.1 屏幕与 DPI 布局

- 为主窗口四个页面及图标选择弹窗统一 DPI 缩放和滚动布局，按钮按文字确定尺寸，列表列宽随窗口宽度调整，标题跟随 DPI。
- 增加 PerMonitorV2 运行时配置和应用清单，由构建、测试、更新及发布脚本一并携带。
- 新增多分辨率、100%～200% 缩放、缩放往返和滚动可达性测试；模拟场景与实际显示器测试的区别见开发说明。
- 简化系统适配页提示，沿用 0.4.0 的原生 v5 核心；用户分组及启动设置保持兼容。

## 0.4.0 动态系统适配

- 从固定 RVA 白名单改为独立符号解析器，按组件身份获取微软符号、验证函数地址并缓存适配数据。
- 增加系统适配页、异步准备、取消、超时和下载失败重试；首次展开托盘面板时继续验证界面结构。
- 原生 DLL 升级为 v5，控制协议升级为 v2，新增界面验证状态查询命令。
- 固定符号表移入原生回归测试；发布包携带解析器，排除机器适配文件和微软符号缓存。

## 0.3.0 代码结构整理

本次整理以 0.2.1 为基线，保留现有界面、图标、分组规则、选择加入、拖动及自动刷新行为。

- 主窗口分为生命周期、布局、文件夹操作和图标列表四个文件；公共控件创建函数单独维护。
- 抽出核心控制与连接接口、图标读取器、兼容性检查和命令行处理。
- 测试移到 `tests`，编译成独立程序；正式 EXE 不再包含自测代码。
- 原生核心按职责拆分为 `.inc` 实现片段，仍保持同一个编译单元和原定义顺序。
- 版本号与原生 DLL 名称统一放入 `project.psd1`，由构建生成 C# 元数据。
- 构建产物、当前安装、默认配置、个人数据和发布包分别管理。
- 增加保留配置的更新脚本、发布白名单和 SHA256 清单。
- 删除未调用的 `ClearAssignments` 方法，统一源码排版，并补充开发说明。

验证结果：

1. C# 与 C++ 完整编译成功。
2. 配置、手动归属优先级、重排、分组操作、刷新、未保存输入和窗口布局测试通过。
3. 核心状态转换、重连、刷新返回“尚未展开”及停止失败处理测试通过。
4. 普通、最小和放大窗口均通过控件边界与标题完整性检查，并检查了窗口渲染。
5. 更新脚本验证现有配置文件哈希保持一致；同名但内容不同的原生 DLL 被拒绝覆盖。
6. 发布包验证默认配置、排除运行时/测试产物，以及全部清单文件哈希。
7. 原生拆分内容重组后与原文件一致；新旧 DLL 的 `.text` 机器代码段逐字节相同。
